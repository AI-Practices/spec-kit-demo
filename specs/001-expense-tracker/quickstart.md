# Quickstart: Expense Tracker

## Prerequisites

- Node.js >= 18
- npm

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Content |
|-------|---------|
| `/` | Dashboard — total spending + 5 most recent expenses |
| `/expenses` | Full expense list with add form and delete buttons |

## Usage

1. Navigate to **/expenses**
2. Fill in the amount (in cents — e.g., 1500 = $15.00), date, category, and description
3. Click **Add Expense** — it appears in the list immediately
4. Click **Delete** on any expense row to remove it
5. Visit the **Dashboard** (/) to see your total spending and recent activity

## Category Labels

Food & Dining, Transportation, Housing, Utilities, Entertainment, Shopping, Health, Other
